## Features
- **Hero Artwork**: Circular orbital frame with ambient glow, rotating dashed rings, and elevated HR manager PNG cutout with floating stats cards (`2,000+ Placed` & `Verified by PlacioBridge`).
- **Student Portal**: Free registration, login, and one-click application submission with status tracking (`Applied`, `Under Review`, `Shortlisted`, `Rejected`, `Hired`).
- **Search & Filters**: Search across roles by skills (`React`, `Next.js`, `Python`, `Cloud & DevOps`, `Applied AI`, `Docker`) and job types (Full-time, Internship, Part-time, Contract).
- **PlacioBridge Verified Roles**: Pre-seeded with authentic engineering roles from PlacioBridge Technologies LLP.
- **Dedicated Company Views**:
  - `#/how`: Transparent 3-phase hiring workflow.
  - `#/about`: Company background, tech tracks, and mission.
  - `#/contact`: Interactive inquiry form with live Pune headquarters address, phone, and direct email.
  - Global 4-column footer with quick links and company credentials.
- **Admin Control Center**: Job posting CRUD, applicant pipeline review with status updates, and live platform statistics.
- **Database & Storage**: SQLite (`techhire.db`) with WAL mode, easy migration path to PostgreSQL.

## Quick Start

### 1. Install & Build
```bash
npm install
npm run build
```

### 2. Start Application
```bash
npm start
```
Open **`http://localhost:8080`** in your browser.

### 3. Development Mode
To run with live reload:
```bash
npm run dev
```
Open **`http://localhost:5173`** (Vite proxies API calls to port 8080).
